# Supply-chain-Risk-Inventory-Buffer-Analytics

## Business Tasks 
- Assess global supplier distribution to pinpoint potential supply chain risks and recommend actionable business solutions.


## Data set
- Custom-generated synthetic supply chain dataset (~10k+ rows across 3 Relational Tables: dim_suppliers, dim_parts, and fact_purchase_orders) designed to mimic real-world semiconductor manufacturing operations


## Tools
- SQL
- PowerBI
